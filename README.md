# 🧪 dragon-express-test — نسخة تجريبية فقط

محاكاة لميزة «صفحة متابعة الشحنة» من ٣ زوايا: المندوب + العميل + الأدمن.
متوصّلة بمشروع Supabase تجريبي (dragon-TEST-tracking) فيه بيانات وهمية بس.
**مالهاش أي علاقة بالتطبيق الحي ولا بقاعدة بياناته.**

- `sim.html` — المحاكاة الكاملة (الشاشات التلاتة جنب بعض ومتزامنة)
- `courier.html` — تطبيق المندوب (تاب «تسليم»)
- `admin.html` — شاشة الأوردرات عند الأدمن
- `index.html?k=…` — صفحة العميل
- `panel.html` — لوحة التجربة القديمة
